Primeros Comandos de Git.


Git clone: Nos permite clonar el repositorio en la computadora, como descargarlo.
Git status: La diferencia entre lo que hay en repositorio a lo que hay en la carpeta(si no sale en rojo son archivos nuevos que aun no estan guardados, y si sale en verde ya los agregaste)
Git add: Este es para agregar los archivos para guardarlos para esto agregamos el nombre del archivo con la extensión de .txt, ponemos el status y lo visualizamos
Git commit: Guarda las cosas, ponemos el nombre de porque se creo esto.
Git push: Subir lo guardado a Github a diferencia de commit que se guarda en la computadora push lo guadar en la nube.

Pasos a seguir para subir tu archivo: 

Abrimos el repositorio en Github 
Creamos una carpeta que identifiquemos, en esta guardaremos el repositorio.
Abrimos la carpeta(Karen) en la parte superior izquierda escribimos cmd, nos abrira el simbolo del sistema, despues nos dirigimos a github y damos click a code y copiaremos el url y utilizaremos git clone y pegamos el url para tenerlo en la computadora. 
Una vez clonado el repositorio abriremos un block de notas para agregar nuestros comentarios
Nos metemos a nuestra carpeta(cd nombre de la carpeta)
Ya una vez editado el archivo y guardado vemos que cambios hay.
git status este debe salir en rojo el nombre del archivo
Después git add .  + el nombre del archivo y la extensión .txt para preprar lo que editaste
ahora si vamos a guardarlo en la compu git commit -m "nombre que asignaste"
Después ponemos git push para guardarlo en la nube  

Si en otra computadora trabajaste y deseas agregar los nuevos archivos lo que debes hacer es entrar al Simbolo del sistema( cmd) y buscar las carpeta donde tienes tus archivos y
insertamos git pull para que estos se guarden en tu computadora y los puedas editar. 
Recuerda siempre ver en donde te encuntras para que agreges tus archivos de forma correcta. 
 
Para editar nuestro archivo ponemos:
notepad (nombre del archivo.txt)
Lo editas y lo guardas
Ponemos git add .
git commit -m "Lo que cambiaremos"
git push 


Agregar un nuevo archivo de datos
notepad(nombre del nuevo archivo.txt)
git add .
git commit -m "La información que hay"
git push


Git Pull: Descarga los cambios mas recientes de un repositorio remoto y los integra de inmediato en tu rama local. 
Manera de hacerlo, entramos a cmd, y colocamos dir, despues nos pondrá las carpetas que tenemos en nuestra computadora, buscamos la de Aprendizaje_Java y entramos a ella con cd una vez dentro escribimos  git pull y nos debe mostrar lo que tenemos en la carpeta y loas cambios que se agregaron. 

Al seguir estos pasos lo que yo note es que los cambios y cosas que escribí en la otra computadora ya se podían ver en mi computadora y tambien las nuevas ramas que agregue. 


GitHub Copilot: Es un asistente de IA que te ayuda escribir código mientras programas, te sugiere como a completar alguna instrucción de tu código, identifica posibles errores. 
La manera de utilizarlo:
1.- Necesitas instalar Visual Studio y tener activa tu cuenta de Git.
2.-En el menú encuentras las extensiones, buscas GitHub copilot, e instalas la extensión.
3.- Abre el proyecto y de tu lado derecho encontraras el chat y puedes preguntarle 

Entre los que se ocupan son el modelo Clauden, es una inteligencia artificial que te ayuda a resolver tareas de forma rapida, lo puede ocupar como un asistente de programación rapida. 
Si ya tiene el GitHub y el Visual, abres el chat de Copilot y buscas el modelo Clauden 4.5, y puedes preguntarle algo o que te enseñe a resolver algo de tu codigo. 


Git Extension: Es una aplicación visual de interfaz grafica que permite administrar respositorios de GIT sin necesidad de usar la linea de comandos. 
Visualización: Muestra de forma grafica los cambios, las ramas, las confirmaciones y el historial de tu proyecto.
Gestión de codigo: Permite crear, clonar, fusionar, y enviar cambios a repositorios remotos mediante botones y menus. 
Integración: Funciona de manera independiente, pero tambien se integra con el explorador Windows y como entornos Visual Studio
