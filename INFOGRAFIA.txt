WinSCP:Es un programa sirve para transferir archivos de forma segura entre una computadora local y un servidor remoto; nos permite ver los archivos, editarlos, sincronizar carpetas y protege tus datos 

PUTTY: Un programa que permite conectarse desde tu computadora a otros equipo o servidores de forma remota, en PuTTY puedes ver el servidor de la empresa en tu computadora al introducir la direccion del servidor al que te conectaras. 
SSH:  Administra servidores en la nube mediante líneas de comandos, conexiones remotas, comunicarse con dispositivos, switches.
La diferencia entre ambos es que en PuTTY trabajas con comandos, te conectas al servidor mediante SSH, usas cd, java y la interfaz tipo terminal y con WinSCP trabajas con archivos los transfieres mediante SSH, ocupas .jar al subir al servidor y la interfaz es tipo explorador de archivos. 

"Servidor" Equipo que almacena, procesa y envía datos a otros dispositivos a través de una red, un servidor recibe solicitudes, las procesa y devuelve una respuesta. Es una maquina potente diseñada para almacenar datos y dar servicios a muchos usuarios o computadores al mismo tiempo. 
Servidores Web: Entrega paginas web
Servidor de aplicaciones: Ejecuta la lógica de una aplicación 
Servidor de Base de Datos: Guardar y consulta datos 
Servidor de API: Recibe solicitudes y devuelve datos 
Son los servidores que se utilizan mas en Java

"Comandos usados en un servidor(Linux)"

pwd: Muestra en que carpeta estas
ls: Muestra archivos  y carpetas
cd: Entrar a una carpeta
cd .. Regresar una carpeta 
mkdir: Crear una carpeta 
touch: Crear un archivo 
cp: Copiar archivos
mv: Mover o cambiar nombre
rm: Eliminar un archivo 
cat: Ver el contenido de un archivo
