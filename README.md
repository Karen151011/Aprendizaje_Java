"GIT"
Herramienta base de control, en el regsitras el cambio del codigo y tienes: intt, add, comint, push, pull status.
Este tiene ramas.
intt:nuevo     add:preparar   comint:copiar   push:cambios    pull: cambios para otros   status: cambios no guardados 

Las ramas se basan y estan conectados con Gitflow, esta nos permite estructurar de manera eficientes.
Este esta compuesto para main:guarda el codigo, develop: se unen las nuevas funciones- acomulan cambios, Feature: funciones nuevas- se fucionan con los cambios  Releave: prepara y pule una nueva version Hotfix: arregla errores urgentes. 

Estructura:                                    Se una al Devlop------se une a feature
                               Main---------                   ------ se une un release
                                                               -------- se une a hotfix

"JAVA"

Lenguaje de programacion, sirve para crear aplicaciones de escritorio, sistemas empresariales, aplicaciones, servicios en la nube, y herramientas, para utilizarlo ocupas la instalcion de JDK elegri un programa paraescribir codigo.

POO: Programa orientado a datos, un estilo de sofware, en donde se estructuran, almacenan y mueven los datos, manteniendo las funciones a la logica. 
Este consiste en crear objetos que contienen tanto datos como metodos, es idealpara crear codigo.
Tiene clases y objetos, las clases es una plantilla para objetos y un objeto es una instancia de una clase. 
Clase: Frta   Objetos: Manzana, banana, ect. 
Esta se aplica estructurando el codigo en clases(moldes) y objetos utilizando 4 pilares:
Emcapsular: Ocultar el estado interno de un objeto
Herencia: Permitir que una clase nueva adquiera atributos y metedos de otra clase.
Polimorfismo: Permitir que un metodo un objeto se compartan de diferentes maneras. 
Abstraccion: Exponer solo lo relevante de un objeto y oculta detalles complejos 

Varriable: Un espacio de memoria de RAM del equipo que sirve para almacenarun dato especifico durante la ejecucion del programa. 
Es altamente tipado y cada variable debe tener un tipo de dato definido. 
int edad= 25; Entero 
double: 19.9; decimal
string: ana; texto
boolean =true; valor falso true

Es un marco de trabajo que ayuda al equipo a resolver los problemas mediante ciclos de trbajao llamados Sprints.
Nos ayuda a desarrollar sofware de manera mas eficiente y agilizada y hay tres roles Product Owner: Represent los intereses del cliente , Scrum Master: Facilita el proceso y el Equipo de desarrollo que construye el proyecto, cada dia se reunene en los Daily Scrum donde ven el avance y quitan los obstaculos
